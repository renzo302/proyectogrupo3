# FrameworkLab — Semana 15
Requiere Node.js 24 LTS recomendado. Desde esta carpeta: `npm install`, `npm run build`, luego abrir `src/index.html` en el navegador. Para editar con recompilación automática: `npm run dev`.
Se incluye el cuarto taller del reto. La paleta se comparte en @theme; cada página conserva su contenido y composición. Por ejemplo bg-marca-700 reutiliza el color de acción.
